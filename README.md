# motivar-investir

Página que mostra o que o seu dinheiro paga na vida real: quanto um valor investido (ou gasto) representa em meses de conta de luz, internet, celular, mercado, gasolina (em quilômetros), viagem, restaurante e cinema, todo ano, para sempre.

- Modo **Investir** e modo **Gastar**
- Sliders de valor, aporte mensal e anos
- Preços médios editáveis, salvos no navegador

Site: https://kaique-fhs.github.io/motivar-investir/
